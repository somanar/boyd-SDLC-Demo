# Generate Documentation

Choose the most appropriate document type from the request and available context.

Only include applicable sections.

Use diagrams in Mermaid when a diagram materially improves understanding and Mermaid is acceptable for the target.

Do not invent URLs, owners, environment names, ticket IDs, or system behavior. Mark missing operational details as `TBD`.
